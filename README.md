# مِشراق / MISHRAQ

منصة ويب لتقييم إمكانات الطاقة الشمسية على أسطح المباني في سلطنة عُمان. نسخة تجريبية تعمل بالكامل في المتصفح، دون خادم خلفي أو خطوة بناء.

## التشغيل على الجهاز

انقر مرتين على `start-local.bat`، وستفتح المنصة على `http://localhost:4173/`.

لا يكفي فتح `index.html` مباشرة، لأن المتصفح يمنع وحدات JavaScript خارج خادم.

## النشر على Vercel

المشروع موقع ثابت لا يحتاج إلى إعدادات بناء:

1. ارفع هذا المجلد إلى مستودع GitHub.
2. من vercel.com اختر **Add New → Project** واستورد المستودع.
3. اترك **Framework Preset** على **Other** واترك أمر البناء فارغًا، ثم اضغط **Deploy**.

## ربط قاعدة البيانات وتسجيل الدخول

المنصة تعمل بدون حساب وتحفظ في المتصفح. لتفعيل الحسابات والحفظ السحابي:

1. أنشئ مشروعًا على supabase.com.
2. من **SQL Editor** نفّذ محتوى `supabase/schema.sql`.
3. من **Project Settings → API** انسخ **Project URL** والمفتاح العام **anon** إلى `js/config.js`. لا تستخدم مفتاح `service_role` هنا أبدًا.
4. من **Authentication → URL Configuration** أضف رابط المنصة على Vercel إلى **Site URL** و**Redirect URLs**.

## بنية المشروع

| المسار | الوظيفة |
|---|---|
| `js/engine/solar.js` | نموذج الإنتاج الكهربائي الشهري |
| `js/engine/layout.js` | توزيع الألواح هندسيًا |
| `js/engine/vision.js` | كشف السطح بنقرة من الصور |
| `js/engine/imagery.js` | تحديد أعلى دقة صور متاحة لكل موقع |
| `js/engine/analyze.js` | ربط التحليل ومستويات الثقة |
| `js/services.js` | Nominatim وOverpass وNASA POWER |
| `js/store.js` | حالة المشروع والافتراضات الافتراضية |
| `js/cloud.js`، `js/account.js` | الحسابات والمزامنة ونوافذ الدخول |
| `supabase/schema.sql` | جداول قاعدة البيانات وسياسات الوصول |
| `js/views/` | الصفحات: الرئيسية، الخريطة، اللوحة، المنهجية، التقرير |

## قيود يجب حلها قبل الإطلاق العام

- **المشاركة:** كل حساب يرى مشروعه فقط. العمل الجماعي يحتاج إلى أدوار وصلاحيات مشتركة.
- **الخدمات العامة:** Nominatim وOverpass خدمات مجانية محدودة السعة وليست مخصصة لحمل إنتاجي.
- **شروط الاستخدام:** يجب مراجعة شروط Esri وNASA POWER وOpenStreetMap للاستخدام المعتمد، ولا سيما اشتقاق البيانات من الصور.
- **الذكاء الاصطناعي:** الكشف الحالي رؤية حاسوبية تقليدية. نموذج التعلم العميق يحتاج إلى بيانات تدريب من عُمان.
